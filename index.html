JARVIS

A personal voice assistant that runs on my own Windows PC.

JARVIS is a hobby project built for a single user — me. It listens for a wake phrase, carries out spoken instructions on my computer, and answers questions. It is not a product, it is not for sale, and it is not distributed to anyone else.

What it does

  • Opens applications, controls volume and brightness, takes screenshots, reports system status.
  • Searches the web, checks the weather, reads the news.
  • Keeps notes, task lists, timers and reminders.
  • Reads and searches my Gmail, and writes draft replies for me to review.
  • Reads my Google Calendar to tell me what is coming up.
  • Plays music, and describes what is on my screen when asked.

How it uses Google data

Two scopes, requested narrowly

  • gmail.modify — read and search my mail, and create drafts. Deliberately not gmail.send: JARVIS writes a draft and I press send. An assistant that could send mail on its own is one bad transcription away from emailing something I never said.
  • calendar.readonly — read my schedule. It cannot change it.

Mail and calendar data are read only when I ask for them, used to answer that request, and not stored beyond my own machine. When I ask JARVIS to summarise or explain a message, the text of that message is sent to the language model that answers the question — which is a third-party service. That is described in full, without euphemism, in the privacy policy.

Where it runs

Entirely on one Windows PC. Speech recognition runs locally via Whisper, and wake-word detection runs locally via openWakeWord — neither sends audio anywhere. There is no server, no account, no telemetry, and no analytics.
